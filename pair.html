2. Spotify

Needs Spotify Premium and a free Spotify developer app (one-time, see below). Your sign-in token goes from this page to the glasses through the relay, which holds it for up to 12 hours under your private pairing code; it is not stored on this page.

How to create the Spotify developer app
  1. Go to developer.spotify.com/dashboard, sign in with your Spotify account, and press Create app.
  2. Name: anything (e.g. CycleHUD). Redirect URI: (press Add). API: tick Web API. Save.
  3. Open the app's Settings and copy the Client ID into the box above.
  4. Have CycleHUD open on the glasses, then press Connect Spotify. After you approve, this page sends the token to the glasses and they show "Spotify connected".

3. Plex / Plexamp

Your Plex Media Server must be reachable from the internet (Settings → Remote Access). Use its secure plex.direct address so the glasses can talk to it over HTTPS.

Finding the address and token
  1. Open plex.tv/api/resources?includeHttps=1&X-Plex-Token=YOUR-TOKEN in a browser. Under your server, copy a uri that ends in .plex.direct:32400 and is not a local address.
  2. Token: in Plex Web, open any track → ⋯ → Get Info → View XML. The page address ends with X-Plex-Token=…; copy that value.
  3. Press Test while Plexamp is playing. It should show the current track. Then Send to glasses.

Anyone who knows your pairing code could send settings to your glasses. Use New code on the glasses any time to change it.

4. Ride log

For checking the map's heading after a ride. On the glasses choose Menu → Status → Send ride log: the file (every GPS fix and what the map made of it) comes to this page through the relay and is kept for 3 hours. Replay it in a desktop browser with index.html?replay=URL.
